## UMLの使い分け（方針）

| UML/図 | 主な用途 | 記載場所 |
|---|---|---|
| ユースケース図 | 機能要件（誰が何をできるか） | 要件定義書 §5 |
| アクティビティ図 | 業務フロー | 要件定義書 §4 |
| クラス図 | ドメインモデル | 設計書 §3 |
| シーケンス図 | 機能の処理フロー | 設計書 §4・§6・§8 |
| 状態遷移図 | ライフサイクル（注文ステータス等） | 設計書 §4 |
| ER図 | データベース | 設計書 §5 |
| コンポーネント図 / 配置図 | アーキテクチャ・インフラ | 設計書 §1・§7 |

図はMermaidを基本とし、必要に応じてPlantUMLを使う。
