# 画面イメージ受け取りボックス

指示者（設計者・PO）から Claude Code に「このような画面にしたい」というイメージを伝えるためのファイル置き場です。ここに書かれた要望は、対応する `../sc-XX-*.md` に反映されます。

## 3つの伝達方式（併用可）

| 方式 | 適した場面 | 手順 |
|---|---|---|
| **B. 会話に ASCII ワイヤを貼る** | 軽い要望・素早く伝えたい | コードブロックで罫線を書いて貼り、「これに沿って SC-XX を作って」と依頼 |
| **C. このフォルダにファイルを置く** | 議論を git で追いたい・複数回の往復が見込まれる | 下記テンプレに沿って `sc-XX.md` を作成 |
| **D. ローカル画像を Read で渡す** | 既存ラフ・スクショ・手書きスケッチを見せたい | リポジトリ**外**（`/tmp/`, `~/Desktop/` 等）にファイルを置き、「`<パス>` を Read で見て」と指示 |

> 画像ファイルは**リポジトリにコミットしない**でください（リポジトリの方針: テキスト・ベクターのみ）。

## ファイル名規約（方式 C）

```
sc-{画面ID}.md
```

例: `sc-03.md`（SC-03 日記投稿への要望）。1画面ごとに1ファイル。

## テンプレート（方式 C）

新規ファイルは下記をコピペして埋めてください。すべてのセクションは任意です（書ける範囲で OK、空欄は Claude 側で補完）。

```markdown
# SC-XX 画面イメージ要望

## 目的・コンテキスト
この画面で利用者に何を達成させたいか。背景・課題があれば添える。

## ワイヤーフレーム
ASCII / Markdown / Mermaid いずれでも可。配置・ヒエラルキー・領域がわかれば十分。

例:
\`\`\`
┌──────────────────────┐
│ [Header]             │
├──────────────────────┤
│  [Content]           │
│                      │
└──────────────────────┘
\`\`\`

## 必須要素
- 必ず置きたい UI 要素を箇条書き

## 任意要素 / Nice to have
- あったら嬉しい要素

## 状態の希望
- Loading / Empty / Error / Success について特別な要望があれば

## トーン・雰囲気
- 「シンプル」「やわらかい」「業務的」など定性表現で OK

## 参考
- 参考にしたい既存サービス・スクショパス（`~/Desktop/...` 等）・Figma URL（公開設定）
```

## 反映までの流れ

1. 指示者が方式 B / C / D のいずれかで Claude に伝える
2. Claude が要望を読み、`../sc-XX-*.md` を作成 / 更新
3. 内容を確認、必要なら追加要望を渡して再反映
4. 確定したら、`_requests/sc-XX.md` は **残しても削除しても可**
   - 残す: 議論履歴として後から振り返れる
   - 削除: 最終仕様だけで十分
