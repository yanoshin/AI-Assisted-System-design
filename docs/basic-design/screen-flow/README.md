# 画面遷移図

Daily Diary の画面遷移。画面IDは [基本設計書 §2.1](../基本設計書.md#21-画面一覧) と一致。

- ソースファイル: [`screen-flow.mmd`](screen-flow.mmd)

## 凡例

- 実線: 通常遷移
- 点線: 認証・状態による条件遷移

## 図

    SC01 -->|SSO ログイン成功| SC02

    SC02 -->|一覧を見る| SC04

    SC06 -->|ログアウト| SC01
