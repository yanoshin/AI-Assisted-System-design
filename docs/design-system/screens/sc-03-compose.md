# SC-03: 日記投稿

## 概要

- **目的**: 当日（サーバ現在日）分の日記を新規作成する
- **利用者**: 一般利用者（ログイン済み）
- **前提条件**: ログイン済み / 当日エントリ未作成
- **関連機能ID**: [FN-DIARY-01](../../requirements/要件定義書.md#52-機能一覧)
- **関連 API**: [`POST /api/diary-entries`](../../detail-design/api/openapi.yaml)
- **関連シーケンス**: [post-diary.mmd](../../detail-design/sequence/post-diary.mmd)
- **URL**: `/diary/new`

## ワイヤーフレーム

```
┌────────────────────────────────────────────────────┐
│ [Daily Diary]   [今日の日記] [一覧]    [Avatar▼]  │  ← グローバルヘッダー
├────────────────────────────────────────────────────┤
│                                                    │
│   今日の日記を書く                                 │  ← h1
│   2026-05-25 (月)                                  │  ← 日付（変更不可）
│                                                    │
│   ┌──────────────────────────────────────────────┐ │
│   │ タイトル                                     │ │  ← title
│   └──────────────────────────────────────────────┘ │
│   0 / 100                                          │  ← 文字数カウンタ
│                                                    │
│   ┌──────────────────────────────────────────────┐ │
│   │ 本文                                         │ │
│   │                                              │ │  ← body
│   │                                              │ │     (textarea, 8行程度)
│   │                                              │ │
│   └──────────────────────────────────────────────┘ │
│   0 / 10000                                        │
│                                                    │
│                       [キャンセル]    [保存]       │  ← フッターアクション
│                                                    │
└────────────────────────────────────────────────────┘
```

- ヘッダーは [`../information-architecture.md`](../information-architecture.md#グローバルヘッダーログイン後全画面共通) の共通ヘッダーを継承
- メインコンテンツは中央寄せ・最大幅 720px 程度を想定
- 文字数カウンタは入力に応じてリアルタイム更新、上限超過で赤色

## 画面項目

| 項目 | 型 | 必須 | 桁 / 制約 | 初期値 | 補足 |
|---|---|---|---|---|---|
| 日付ラベル | 表示のみ | — | — | サーバ現在日 (`YYYY-MM-DD (曜)`) | 編集不可 |
| タイトル | text input | ◯ | 1〜100 文字、改行禁止 | 空 | プレースホルダ「今日のひとこと」 |
| 本文 | textarea | ◯ | 1〜10,000 文字 | 空 | プレースホルダ「今日あったことを自由に」 |
| タイトル文字数カウンタ | 表示のみ | — | — | `0 / 100` | 95文字超でグレー→黄、100超で赤 |
| 本文文字数カウンタ | 表示のみ | — | — | `0 / 10000` | 9500超で黄、10000超で赤 |
| 保存ボタン | button | — | — | 活性 | 必須項目が空 / 上限超過時は非活性、送信中はスピナー |
| キャンセル | link button | — | — | — | 入力ありなら確認モーダル、なしなら即 SC-02 へ |

## イベント仕様

| トリガー | 動作 | 遷移先 / 副作用 |
|---|---|---|
| ページ表示 | `GET /api/me` でセッション確認 | 401 なら `/?next=/diary/new` |
| タイトル / 本文 入力 | 文字数カウンタ更新、バリデーション再判定 | 保存ボタンの活性切り替え |
| 保存クリック | `POST /api/diary-entries` `{title, body}` | 成功 (201) → SC-02 + トースト「保存しました」<br>409 → SC-05 (`/diary/{today}`) へリダイレクト + トースト「既に作成済みのため編集画面を開きました」<br>422 → フォーム上部に E_VALIDATION メッセージ<br>5xx → 全画面エラー、再試行リンク |
| Ctrl/Cmd + Enter | 保存と同じ | 同上 |
| キャンセル / Esc | 入力ありなら確認モーダル → 確定で破棄 | SC-02 |
| ブラウザ閉じる / 別ページ遷移 | 入力ありなら `beforeunload` で警告 | — |

## 状態（States）

### Loading
- ページ初期: 「セッション確認中…」を中央に短時間表示（100ms 未満なら出さない）
- 送信中: 保存ボタンをスピナー化、フォーム全体を `aria-busy="true"` + `readonly` 化、キャンセルは活性のまま

### Empty
- このページは入力フォームなので、純粋な Empty 状態は存在しない（初期状態が「Empty」と兼ねる）

### Error
- **バリデーション** (422): フォーム上部に赤いメッセージブロック「入力内容を確認してください」、該当項目に赤枠 + 個別メッセージ
- **重複** (409): SC-05 へ自動リダイレクト（エラーとは扱わず、ガイダンスとして処理）
- **サーバエラー** (5xx): 全画面エラーカード「保存に失敗しました。少し時間をおいて再試行してください」+ 「再試行」ボタン
- **ネットワーク切断**: 同上、メッセージは「通信に失敗しました」
- 詳細メッセージは [interaction-states.md §Error](../interaction-states.md#error-エラー) と [詳細設計書 §2.3](../../detail-design/詳細設計書.md#23-エラーメッセージ) を参照

### Success
- 保存成功 → SC-02 にリダイレクト後、画面右下にトースト「保存しました」を3秒表示
- 即座にダッシュボードの直近一覧に新エントリが反映されている状態

## アクセシビリティ

- **見出し階層**: h1 = 「今日の日記を書く」、その他は構造的見出し不要
- **ラベル**: 「タイトル」「本文」は `<label for>` で明示
- **フォーカス順**: 日付（読み上げのみ）→ タイトル → 本文 → キャンセル → 保存
- **初期フォーカス**: タイトル input に自動でフォーカス
- **キーボード操作**:
  - Tab で順送り、Shift+Tab で戻る
  - Ctrl/Cmd + Enter で保存
  - Esc でキャンセル（モーダル経由）
- **スクリーンリーダー**:
  - ページ表示時に「今日の日記を書く、2026年5月25日 月曜日」と読み上げ
  - 文字数カウンタは `aria-live="polite"`、上限超過時のみ `aria-live="assertive"`
  - 保存中は `aria-busy="true"` を form 全体に付与
  - エラーは `role="alert"`、フォーカスをエラー領域に移動
- **コントラスト**: WCAG 2.1 AA 準拠（本文 4.5:1、補助文字 3:1）
