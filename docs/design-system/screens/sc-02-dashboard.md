# SC-02: ダッシュボード

> 本ファイルは軽量版スケルトンです。完全な記入例は [sc-03-compose.md](sc-03-compose.md) を参照。

## 概要

- **目的**: 当日エントリへの導線 + 直近の振り返りを提供する利用者のホーム
- **利用者**: 一般利用者（ログイン済み）
- **前提条件**: ログイン済み
- **関連機能ID**: FN-DIARY-01（CTA）、FN-DIARY-02（直近一覧）
- **関連 API**: [`GET /api/me`](../../detail-design/api/openapi.yaml), [`GET /api/diary-entries?year=&month=`](../../detail-design/api/openapi.yaml)
- **URL**: `/dashboard`

## ワイヤーフレーム

```
┌────────────────────────────────────────────────┐
│ [Daily Diary]  [今日の日記] [一覧]  [Avatar▼] │
├────────────────────────────────────────────────┤
│                                                │
│   こんにちは、{displayName} さん               │  ← 挨拶 (h1 は装飾でも可)
│                                                │
│   ┌──────────────────────────────────────────┐ │
│   │  今日の日記 (2026-05-25 月)              │ │  ← 当日カード
│   │  [まだ書いていません]   [今日の日記を書く ▸]│ │     or 既にあれば「編集する」
│   └──────────────────────────────────────────┘ │
│                                                │
│   直近の日記                       [一覧を見る]│  ← h2
│   ┌──────────────────────────────────────────┐ │
│   │ 2026-05-24 (日)  今日は散歩した          │ │
│   │ 2026-05-23 (土)  仕事が早く終わって…     │ │
│   │ 2026-05-22 (金)  特に何もなかった        │ │
│   └──────────────────────────────────────────┘ │
└────────────────────────────────────────────────┘
```

## 画面項目

| 項目 | 型 | 補足 |
|---|---|---|
| 挨拶 | 表示 | `こんにちは、{displayName} さん` |
| 当日カード | カード | 当日エントリの有無で表示分岐 |
| 「今日の日記を書く」CTA | button | 未作成時。クリックで SC-03 へ |
| 「編集する」CTA | button | 作成済時。クリックで SC-05 (`/diary/{today}`) へ |
| 直近一覧 | list | 直近7件、各行は `日付` + `タイトル`、クリックで SC-05 |
| 「一覧を見る」 | link | SC-04 へ |

## イベント仕様

| トリガー | 動作 | 遷移先 |
|---|---|---|
| ページ表示 | `GET /api/me` + `GET /api/diary-entries` (当月) | 認証エラーは `/?next=/dashboard` |
| 「今日の日記を書く」 | — | SC-03 |
| 「編集する」 | — | SC-05 (`/diary/{today}`) |
| 直近一覧の行クリック | — | SC-05 (`/diary/{date}`) |
| 「一覧を見る」 | — | SC-04 |

## 状態

- **Loading**: 挨拶以外をスケルトン化（当日カード・直近一覧）
- **Empty**: 直近一覧が0件なら「まだ日記がありません。今日から始めましょう」+ CTA
- **Error**: 全画面エラー「読み込みに失敗しました」+ 再試行
- **Success**: 該当なし（読み取り画面）

## アクセシビリティ

- h1 はサービス名 or 「ダッシュボード」（挨拶はサブ）
- 直近一覧は `<ul>` / `<li>` 構造、各行はキーボード操作可能
- 当日カードの状態（未作成/作成済）は `aria-label` で明示
