# SC-06: アカウント設定

> 本ファイルは軽量版スケルトンです。完全な記入例は [sc-03-compose.md](sc-03-compose.md) を参照。

## 概要

- **目的**: 利用者が自分のアカウント情報を確認し、ログアウト or 退会できる
- **利用者**: 一般利用者（ログイン済み）
- **関連機能ID**: FN-AUTH-02 (ログアウト), FN-AUTH-04 (退会)
- **関連 API**: [`GET /api/me`](../../detail-design/api/openapi.yaml), [`POST /api/auth/logout`](../../detail-design/api/openapi.yaml), [`DELETE /api/me`](../../detail-design/api/openapi.yaml)
- **URL**: `/account`

## 画面項目

| 項目 | 型 | 補足 |
|---|---|---|
| 表示名 | 表示 | `GET /api/me.displayName` |
| メール | 表示 | `(Google)` の註は IdP 種別 |
| 登録日 | 表示 | `createdAt` を `YYYY-MM-DD` で |
| ログアウトボタン | button | 確認なしで実行（軽い操作） |
| 退会ボタン | button | 破壊的、確認モーダル必須 |

## イベント仕様

| トリガー | 動作 | 遷移先 |
|---|---|---|
| ページ表示 | `GET /api/me` | 認証エラー時は `/?next=/account` |
| ログアウトクリック | `POST /api/auth/logout` | SC-01 へリダイレクト + トースト「ログアウトしました」 |
| 退会クリック | 確認モーダル表示（タイトル「アカウントを削除しますか？」、文面で不可逆性を明記） | 「削除する」確定で `DELETE /api/me` → SC-01 + 完了モーダル「アカウントを削除しました」 |

## 状態

- **Loading**: プロフィール領域をスケルトン
- **Empty**: 該当なし
- **Error**: `GET /api/me` 失敗で全画面エラー、退会失敗時はモーダル内でエラー表示
- **Success**: ログアウト → トースト、退会 → モーダル（明示的に閉じてもらう）

## アクセシビリティ

- h1 = 「アカウント設定」、各セクションは h2
- 「アカウントを削除する」ボタンは
  - 色だけに頼らず、ラベルに「削除」を含める
  - `aria-describedby` で警告文と関連付け
  - 確認モーダルではフォーカスを「キャンセル」に初期配置（誤操作防止）
