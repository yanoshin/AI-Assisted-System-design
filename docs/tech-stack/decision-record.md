## 採用一覧（埋まった結果のサマリ）

回答が揃ったら、本セクションを **読みやすい形にまとめ直す**（基本設計書 §1.2 に転記しやすい形式）。

```
- フロントエンド: （例）Next.js (SSR) + Tailwind + TanStack Query
- バックエンド:   Node.js (TypeScript) + Fastify, REST API
- データベース:   PostgreSQL 16
- 認証:           Google OIDC (SSO)
- 監視:           Sentry + CloudWatch
- CI/CD:          GitHub Actions
- テスト:         Vitest + Playwright
```

## 大きな決定は ADR へ昇格

技術選定のうち「**変更時の影響が大きい**もの」「**今後の判断を縛るもの**」は、本ファイルに加えて [`../decisions/`](../decisions/) に ADR として独立記録する。例:
- データベース選定（移行コストが大きい）
- 認証方式の選定（セキュリティ影響が大きい）
- IaC ツールの選定（運用全体に波及する）
