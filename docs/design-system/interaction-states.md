# Interaction States — 共通インタラクション

データ取得・操作の **4状態**（Loading / Empty / Error / Success）の表現規約。全画面で一貫させる。

## 4状態の定義と表現

### Loading（読み込み中）
- **発生**: API 呼び出し中、ページ初期表示中、フォーム送信中
- **表現**:
  - ページ全体: スケルトン UI（骨組みを灰色のブロックで表示）
  - 部分: スピナー（小） + 操作対象を非活性化
  - フォーム送信: 送信ボタンをスピナー化、フォーム全体を read-only
- **時間目安**:
  - 100ms 未満: 何も表示しない（瞬時に見える）
  - 100ms〜1s: スピナー
  - 1s 以上: スケルトン + 「読み込んでいます…」キャプション
- **アクセシビリティ**: `aria-busy="true"` を該当領域に付与

### Empty（データなし）
- **発生**: 一覧が0件、過去日記が1件もない等
- **表現**:
  - アイコン or イラスト（中央配置、控えめ）
  - 「まだ日記がありません」など状況説明
  - 復帰アクション（「今日の日記を書く」ボタン等）を**必ず置く**
- **アクセシビリティ**: 見出し（`h2` 程度）として読み上げ可能に

### Error（エラー）
- **発生**: API エラー、バリデーションエラー、ネットワーク切断
- **表現**:
  - 軽微（バリデーション）: フォーム上部にメッセージブロック、該当項目に赤枠
  - 致命（500系・ネットワーク）: 全画面エラーまたは大きめのバナー
  - 復帰アクション（再試行・前に戻る）を**必ず置く**
- **エラーコード対応**: [詳細設計書 §3.2 エラーコード一覧](../detail-design/詳細設計書.md#32-エラーコード一覧) と [§2.3](../detail-design/詳細設計書.md#23-エラーメッセージ) を参照
- **トーン**: 利用者を責めない。「入力内容を確認してください」「通信に失敗しました」など中立的に
- **アクセシビリティ**: `role="alert"` + フォーカスをエラー領域に移す

### Success（成功）
- **発生**: 保存完了、削除完了、ログイン成功
- **表現**:
  - 一過性: **トースト**（画面右下から3秒間表示、自動消失）
  - 重要: **モーダル**で明示的に閉じてもらう（退会完了等）
  - インライン: フォーム上部に成功メッセージ（編集の更新等）
- **トーン**: 簡潔・能動態。「保存しました」「ログアウトしました」
- **アクセシビリティ**: `role="status"` で読み上げ

## フィードバック手段の使い分け

| 手段 | 用途 | 持続 |
|---|---|---|
| トースト | 軽微な成功・情報 | 3秒で自動消失 |
| インラインメッセージ | フォーム送信結果・バリデーション | 操作で消えるまで |
| モーダル | 確認・致命的なエラー・退会のような重要な完了 | 利用者が閉じるまで |
| バナー | 全画面共通のお知らせ（メンテ予告等） | 閉じるか期間で |

## 共通ルール

1. **状態の重複を避ける**: 1領域で同時に複数の状態を表示しない（Loading 中の Empty 表示はしない）
2. **遷移の予告**: 削除や退会など破壊的操作の前には必ずモーダルで確認
3. **戻れる動線**: Error 状態でも「前に戻る」「再試行」を必ず提供
4. **沈黙しない**: 1秒以上待たせるなら必ず何らかの Loading 表示
5. **エラーログ**: 利用者にエラーコードを見せる場合は技術詳細は出さず、サポートに伝えるための短い ID のみ

## 画面別の状態への当てはめ例

| 画面 | Loading | Empty | Error | Success |
|---|---|---|---|---|
| SC-02 ダッシュボード | スケルトン（直近一覧領域） | 「まだ日記がありません」+ CTA | 全画面エラー | — |
| SC-03 投稿 | 送信ボタンスピナー | — | フォーム上部メッセージ | SC-02 でトースト |
| SC-04 一覧 | カレンダースケルトン | 「この月の日記はありません」 | 全画面エラー | — |
| SC-05 詳細・編集 | コンテンツ領域スケルトン | — | フォーム上部メッセージ | インライン「更新しました」 |
| SC-06 アカウント | プロフィール領域スケルトン | — | 全画面エラー | モーダル（退会完了） |
