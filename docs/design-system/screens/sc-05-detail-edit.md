# SC-05: 日記詳細・編集

> 本ファイルは軽量版スケルトンです。完全な記入例は [sc-03-compose.md](sc-03-compose.md) を参照。

## 概要

- **目的**: 過去日記の閲覧 / 編集 / 削除
- **利用者**: 一般利用者（ログイン済み、対象エントリの所有者）
- **関連機能ID**: FN-DIARY-02 (閲覧), FN-DIARY-03 (編集), FN-DIARY-04 (削除)
- **関連 API**: [`GET / PUT / DELETE /api/diary-entries/{date}`](../../detail-design/api/openapi.yaml)
- **関連シーケンス**: [edit-past-diary.mmd](../../detail-design/sequence/edit-past-diary.mmd)
- **URL**: `/diary/{date}`（`{date}` は `YYYY-MM-DD`）

## ワイヤーフレーム（閲覧モード）

```
┌────────────────────────────────────────────────┐
│ [Daily Diary]   [今日の日記] [一覧]  [Avatar▼] │
├────────────────────────────────────────────────┤
│   ◂ 一覧に戻る                                 │
│                                                │
│   2026-05-22 (金)                              │  ← 日付見出し
│   タイトル                                     │  ← h1
│                                                │
│   本文がここに表示される。                     │
│   複数行にわたる本文…                          │
│                                                │
│   ─────────────────────────                    │
│   作成: 2026-05-22 23:10                       │
│   更新: 2026-05-23 10:05                       │
│                                                │
│           [削除]              [編集する]       │
└────────────────────────────────────────────────┘
```

## ワイヤーフレーム（編集モード）

SC-03 とほぼ同じレイアウト。日付は変更不可、ボタンは `[キャンセル] [更新]`。

## 画面項目（閲覧モード）

| 項目 | 型 | 補足 |
|---|---|---|
| 「一覧に戻る」 | link | SC-04 へ |
| 日付見出し | 表示 | `YYYY-MM-DD (曜)` |
| タイトル | 表示 (h1) | — |
| 本文 | 表示 | 改行・空行を保持してレンダリング |
| 作成日時 / 更新日時 | 表示 | 副情報、小さく表示 |
| 「編集する」 | button | 編集モードに切替 |
| 「削除」 | button | 確認モーダル → 確定で `DELETE` |

## 画面項目（編集モード）

SC-03 と同じ（タイトル / 本文 / カウンタ / キャンセル / 更新）。日付は表示のみで変更不可。

## イベント仕様

| トリガー | 動作 | 遷移先 / 副作用 |
|---|---|---|
| ページ表示 | `GET /api/diary-entries/{date}` | 404 → 「該当日のエントリはありません」表示<br>403 → 「アクセスできません」+ SC-04 への戻り導線<br>200 → 閲覧モードで表示 |
| 「編集する」 | モード切替 | URL は変えず、現在値をフォームに展開 |
| 「更新」 | `PUT /api/diary-entries/{date}` | 成功 → インライン「更新しました」+ 閲覧モードに戻る<br>422 → フォーム上部にエラー |
| 「キャンセル」（編集中） | 入力差分あり → 確認モーダル | 確定で閲覧モード復帰 |
| 「削除」 | 確認モーダル → 「削除する」 | `DELETE /api/diary-entries/{date}` → SC-04 + トースト「削除しました」 |

## 状態

- **Loading**: コンテンツ領域をスケルトン
- **Empty**: 404 受領時「該当日の日記はありません」+ SC-04 へ戻る導線
- **Error**: 401 → ログイン誘導、403 → アクセス不可表示、5xx → 全画面エラー + 再試行
- **Success**: 更新はインライン、削除はトースト

## アクセシビリティ

- h1 = 日記タイトル
- 「削除」は破壊的操作のため、確認モーダル必須・モーダル内では「削除」ボタンに強い色 + `aria-describedby` で警告文を関連付け
- 編集モード切替時にフォーカスをタイトル入力に移す
